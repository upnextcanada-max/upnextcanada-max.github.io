FAQ

Is this app free to use?

Yes! The app is completely free and open-source. You only need to set up your own Instagram API credentials and optionally an OpenArt API key.

How do I get Instagram API credentials?

You'll need to create a Facebook Developer account and set up an app with Instagram API access. Full setup instructions are provided in the documentation.

Do I need a backend server?

Yes, Instagram's API requires a backend service. We provide instructions for deploying free serverless functions on Vercel or Netlify, or you can run a local server for development.

What video formats are supported?

The app supports MP4, MOV, WebM, and AVI formats. MP4 and WebM work best across all browsers.

Is my data secure?

Yes! All video processing happens locally in your browser. Your videos never leave your device. API credentials are stored in your browser's local storage only.

What is OpenArt I2V?

OpenArt I2V (Image-to-Video) is an AI service that generates videos from images. Our app integrates with their API to import and process AI-generated videos.

Can I post multiple screenshots at once?

Yes! Select multiple screenshots, add them to the queue, and post them all to Instagram with one click. Each screenshot becomes a separate post.

Does this work on mobile devices?

Yes, the app is fully responsive and works on mobile devices, though the experience is optimized for desktop browsers.
